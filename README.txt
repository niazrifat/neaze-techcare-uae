# Neaze TechCare UAE Website

This is a free static website. No paid hosting or database is required.

## Open on your computer
1. Extract the ZIP file.
2. Open `index.html` in Google Chrome.

## Publish free with GitHub Pages
1. Create a free account at GitHub.
2. Create a new public repository, for example `neaze-techcare-uae`.
3. Upload all website files.
4. Open repository **Settings > Pages**.
5. Select **Deploy from a branch**, choose `main` and `/root`, then save.
6. GitHub will provide your free website address.

## Publish free with Netlify
1. Create a free account at Netlify.
2. Extract the ZIP.
3. Drag the whole website folder into Netlify's manual deployment page.
4. Netlify will publish the website and give you a free link.
